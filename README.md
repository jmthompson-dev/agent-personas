# Agent Personas

Reusable, project-independent AI agent role definitions for software architecture, product management, AI/ML research, AI engineering, machine learning engineering, full stack development, UI/UX design, quality assurance, and information security.

See [the catalog](agents/README.md) for all eleven roles, responsibilities, boundaries, and invocation guidance.

Persona documents do not create agents or grant access. Supply project-specific requirements and authorized tools when invoking a role.
